El comportamiento de estas funciones es afectado por la configuración en el archivo php.ini.

La tabla siguiente lista las opciones de configuración disponibles para la extensión. Para más información sobre estas opciones, consúltese el capítulo sobre la gestión de errores y alertas SQLSRV.

Nombre Por defecto Cambiable Historial de cambios

sqlsrv.LogSubsystems 0 INI_ALL Disponible a partir de SQLSRV 1.0
sqlsrv.LogSeverity 1 INI_ALL Disponible a partir de SQLSRV 1.0
