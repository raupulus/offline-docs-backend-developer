El comportamiento de estas funciones es afectado por la configuración en el archivo php.ini.

Opciones de configuración iconv

Aquí hay una aclaración sobre el uso de las directivas de configuración.

[!WARNING] Algunos sistemas (como IBM AIX) utilizan "ISO8859-1" en lugar de "ISO-8859-1", por lo que este valor debe ser utilizado en las opciones de configuración así como en los argumentos de las funciones.

iconv.input_encoding string

[!WARNING] Esta funcionalidad está OBSOLETA a partir de PHP 5.6.0. Depender de esta funcionalidad está altamente desaconsejado.

Los usuarios de PHP 5.6 y versiones posteriores deben dejar esta opción vacía y definir en su lugar la opción input_encoding.

iconv.output_encoding string

[!WARNING] Esta funcionalidad está OBSOLETA a partir de PHP 5.6.0. Depender de esta funcionalidad está altamente desaconsejado.

Los usuarios de PHP 5.6 y versiones posteriores deben dejar esta opción vacía y definir en su lugar la opción output_encoding.

iconv.internal_encoding string

[!WARNING] Esta funcionalidad está OBSOLETA a partir de PHP 5.6.0. Depender de esta funcionalidad está altamente desaconsejado.

Los usuarios de PHP 5.6 y versiones posteriores deben dejar esta opción vacía y definir en su lugar la opción default_charset.
