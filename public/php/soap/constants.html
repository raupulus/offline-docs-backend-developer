Constantes predefinidas#

Estas constantes son definidas por esta extensión, y solo están disponibles si esta extensión ha sido compilada con PHP, o bien cargada en tiempo de ejecución.

SOAP_1_1 (int) 1 Especifica el uso de SOAP 1.1 cuando se pasa como opción soap_version a SoapServer::__construct o SoapClient::__construct.
SOAP_1_2 (int) 2 Especifica el uso de SOAP 1.2 cuando se pasa como opción soap_version a SoapServer::__construct o SoapClient::__construct.
SOAP_PERSISTENCE_SESSION (int) 1 Especifica el uso del encodado SOAP cuando se pasa como opción use al método SoapClient::__construct.
SOAP_PERSISTENCE_REQUEST (int) 2 Especifica el uso de un encodado específico del servicio cuando se pasa como opción use a SoapClient::__construct.
SOAP_FUNCTIONS_ALL (int) 999 Obsoleta a partir de PHP 8.4.0.
SOAP_ENCODED (int) 1 Especifica el uso de un enlace de estilo RPC cuando se pasa como opción style a SoapClient::__construct.
