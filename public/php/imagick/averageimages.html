Imagick::averageImages

Promedio de un conjunto de imágenes

[!WARNING] Esta función está DEPRECADA a partir de Imagick 3.4.4. Depender de esta funcionalidad está fuertemente desaconsejado.

Descripción#

php public Imagick::averageImages(): Imagickphp

Realiza el promedio de un conjunto de imágenes.

Parámetros#

Esta función no contiene ningún parámetro.

Valores devueltos#

Devuelve un nuevo objeto Imagick en caso de éxito.

Errores/Excepciones#

Lanza una ImagickException en caso de error.
