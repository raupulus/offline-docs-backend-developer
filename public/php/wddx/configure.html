Instalación#

PHP 7.4#

Esta extensión ha sido movida al módulo PECL y no será integrada en PHP a partir de PHP 7.4.0

Información sobre la instalación de estas extensiones PECL puede ser encontrada en el capítulo del manual titulado Instalación de extensiones PECL. Otra información como notas sobre nuevas versiones, descargas, fuentes de ficheros, información sobre los mantenedores así como un CHANGELOG, pueden ser encontradas aquí: https://pecl.php.net/package/wddx.

PHP \< 7.4#

Después de instalar la librería requerida Expat, compile PHP con --enable-wddx y utilice --with-libexpat-dir para Expat.

La versión Windows de PHP dispone del soporte automático de esta extensión. No es necesario añadir ninguna biblioteca adicional para disponer de estas funciones.
