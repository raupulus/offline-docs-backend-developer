Uso básico

Básica ejecución Javascript

<?php

$v8 = new V8Js();

/* basic.js */
$JS = <<< EOT
len = print('¡Hola' + ' ' + 'Mundo!' + "\\n");
len;
EOT;

try {
  var_dump($v8->executeString($JS, 'basic.js'));
} catch (V8JsException $e) {
  var_dump($e);
}

?>

El ejemplo anterior mostrará:

¡Hola Mundo!
