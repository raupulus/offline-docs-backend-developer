SolrDocument::offsetGet

Recupera un campo

Descripción#

php public SolrDocument::offsetGet(string $fieldName): SolrDocumentFieldphp

Se usa para recuperar un campo cuando el objeto es tratado como una matriz.

Parámetros#

fieldName
El nombre del campo.

Valores devueltos#

Devuelve un objeto SolrDocumentField.
