ReflectionProperty::export

Exporta

[!WARNING] Esta función está OBSOLETA a partir de PHP 7.4.0, y ha sido ELIMINADA a partir de PHP 8.0.0. Depender de esta función está altamente desaconsejado.

Descripción#

php public static ReflectionProperty::export(mixed $class, string $name, [bool $return]): stringphp

Exporta una reflexión.

[!WARNING] Esta función está actualmente no documentada; solo la lista de sus argumentos está disponible.

Parámetros#

argumento
La reflexión a exportar.

name
El nombre de la propiedad.

return
Definirlo a true retornará la exportación en lugar de emitirla. Definirlo a false (por defecto) hará lo contrario.
