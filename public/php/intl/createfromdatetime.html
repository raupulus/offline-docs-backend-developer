IntlGregorianCalendar::createFromDateTime

Crear una nueva instancia de IntlGregorianCalendar a partir de una fecha y hora

Descripción#

public static IntlGregorianCalendar::createFromDateTime(int $year, int $month, int $dayOfMonth, int $hour, int $minute, [int $second]): static
```php

Crear una nueva instancia de `IntlGregorianCalendar` a partir de una fecha y hora.

## Parámetros

`year`  
El nuevo valor para `IntlGregorianCalendar::FIELD_YEAR`.

`month`  
El nuevo valor para `IntlGregorianCalendar::FIELD_MONTH`. La secuencia de los meses comienza en cero, es decir, enero está representado por 0, febrero por 1, ..., diciembre es 11 y Undécembre (si el calendario lo permite) es 12.

`dayOfMonth`  
El nuevo valor para `IntlGregorianCalendar::FIELD_DAY_OF_MONTH`.

`hour`  
El nuevo valor para `IntlGregorianCalendar::FIELD_HOUR_OF_DAY`.

`minute`  
El nuevo valor para `IntlGregorianCalendar::FIELD_MINUTE`.

`second`  
El nuevo valor para `IntlGregorianCalendar::FIELD_SECOND`.

## Valores devueltos

Devuelve una nueva instancia de `IntlGregorianCalendar`.
