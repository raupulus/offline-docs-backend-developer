token_name

Obtiene el nombre simbólico de un token PHP dado

Descripción#

token_name(int $id): string
```php

`token_name` obtiene el nombre simbólico para un valor de `id` PHP.

## Parámetros

`id`  
El valor token.

## Valores devueltos

El nombre simbólico para el `id` dado.

## Ejemplos

`token_name` ejemplo
"T_EVAL" // una constante token mapea a su propio nombre echo token_name(T_FUNCTION); // -> "T_FUNCTION" ?>
