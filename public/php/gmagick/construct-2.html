GmagickPixel::__construct

El constructor GmagickPixel

Descripción#

php public GmagickPixel::__construct([string $color])php

Construye un nuevo objeto GmagickPixel. Si se especifica un color, el objeto es construido y luego inicializado utilizando este color antes de ser devuelto.

Parámetros#

color
El color a utilizar como valor inicial de este objeto (opcional).
