SplObserver::update

Recibe actualizaciones de sujeto

Descripción#

php public SplObserver::update(SplSubject $subject): voidphp

Este método es llamado cuando cualquier SplSubject se use para llamar llamadas adjuntas SplSubject::notify.

[!WARNING] Esta función está actualmente no documentada; solo la lista de sus argumentos está disponible.

Parámetros#

subject
El objeto SplSubject notificando al observador de una actualización.

Valores devueltos#

No se retorna ningún valor.
