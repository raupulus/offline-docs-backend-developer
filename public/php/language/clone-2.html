Exception::__clone

Clona la excepción

Descripción#

php private Exception::__clone(): voidphp

Exceptions no se pueden clonar, y el intento de hacerlo lanzará un Error.

Parámetros#

Esta función no contiene ningún parámetro.

Valores devueltos#

No se retorna ningún valor.

Errores/Excepciones#

Las Excepciones no se pueden clonar.
