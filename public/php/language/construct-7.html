Error::__construct

Construir el objeto error

Descripción#

php public Error::__construct([string $message], [int $code], [Throwable $previous])php

Construye el Error.

Parámetros#

message
El mensaje de error.

code
El código de error.

previous
El objeto Throwable anterior empleado para la cadena de excepciones.

Notas#

[!NOTE] El parámetro message NO es seguro a nivel binario.
