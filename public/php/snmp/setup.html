Instalación/Configuración#

Requisitos#

Para utilizar las funciones SNMP, es necesario instalar el paquete NET-SNMP. Las funciones SNMPv3 solo están disponibles cuando el paquete OpenSSL está instalado.

La versión Net-SNMP 5.3+ es necesaria para las instalaciones en Unix, y la versión Net-SNMP 5.4+ para Windows.
