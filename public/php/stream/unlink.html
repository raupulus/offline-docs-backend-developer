streamWrapper::unlink

Borrar un archivo

Descripción#

php public streamWrapper::unlink(string $path): boolphp

Este método es llamado en respuesta a unlink.

[!NOTE] Para que el mensaje de error apropiado sea devuelto, este método no debería ser definido si la envoltura no soporta la eliminación de archivos.

Parámetros#

path
LA URL del archivo que debería ser borrado.

Valores devueltos#

Esta función retorna true en caso de éxito o false si ocurre un error.

Errores/Excepciones#

Emite una advertencia E_WARNING si la llamada a este método falla (i.e. no implementado).

Notas#

[!NOTE] La propiedad streamWrapper::$context es actualizada si un contexto válido es pasado a la función.
