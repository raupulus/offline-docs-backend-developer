mcrypt_module_close

Libera el módulo de cifrado

[!WARNING] Esta función está OBSOLETA a partir de PHP 7.1.0 y ha sido ELIMINADA a partir de PHP 7.2.0. Depender de esta función está altamente desaconsejado.

Descripción#

php mcrypt_module_close(resource $td): boolphp

Libera el módulo td.

Parámetros#

td
El recurso de cifrado.

Valores devueltos#

Esta función retorna true en caso de éxito o false si ocurre un error.
