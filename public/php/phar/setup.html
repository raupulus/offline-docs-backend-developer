Instalación/Configuración#

Requisitos#

Puede ser deseable activar las extensiones zlib y bzip2 para aprovechar el soporte de archivos phar comprimidos. Asimismo, para utilizar las firmas OpenSSL, la extensión OpenSSL debe ser activada.

Si zend.multibyte está activado, zend.detect_unicode también debe estar activado.

Tipos de recursos#

La extensión Phar proporciona el flujo phar, que permite el acceso de forma transparente a los ficheros contenidos en un phar. Para más información, consulte el formato de archivo Phar
