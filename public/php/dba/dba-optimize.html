dba_optimize

Optimiza una base DBA

Descripción#

php dba_optimize(Dba\Connection $dba): boolphp

dba_optimize optimiza la base de datos subyacente.

Parámetros#

dba
Una instancia de Dba\Connection, devuelta por dba_open o dba_popen.

Valores devueltos#

Esta función retorna true en caso de éxito o false si ocurre un error.

Historial de cambios#

Versión Descripción
8.4.0 El parámetro dba ahora espera una instancia de Dba\Connection ; anteriormente, se esperaba un resource dba válido.
