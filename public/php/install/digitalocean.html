DigitalOcean#

DigitalOcean ofrece las siguientes plataformas para instalar PHP y ejecutar una aplicación web en su infraestructura de alojamiento en la nube.

  • Cloudways: Despliegue en un clic de las principales aplicaciones PHP: WordPress, Magento, Drupal, Laravel y más.
  • Droplet: Máquinas virtuales para instalar PHP y otros programas. Instalación de una pila LAMP en un servidor Linux .
  • Plataforma de aplicaciones: Gestione infraestructuras para crear, implantar y escalar aplicaciones rápidamente. Aprenda a ejecutar aplicaciones PHP en la App .
  • Funciones: Plataforma sin servidor que permite a los desarrolladores ejecutar código sin aprovisionar ni gestionar servidores. PHP es compatible de forma nativa. Aprenda a crear funciones sin servidor en PHP .
