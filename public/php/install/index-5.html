Instalación en sistemas Windows#

Las versiones oficiales de PHP en Windows son recomendadas para uso en producción, pero PHP también puede ser compilado desde el código fuente.

PHP también se puede instalar en Azure App Services (también conocido como Microsoft Azure, Windows Azure o (Windows) Azure Web Apps).

La sección de instalación de las preguntas frecuentes abarca problemas comunes de instalación y configuración que podrían encontrarse.
