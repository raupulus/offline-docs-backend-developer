DOMDocument::schemaValidate

Valida un documento basado en un esquema. Sólo se admite XML Schema 1.0.

Descripción#

php public DOMDocument::schemaValidate(string $filename, [int $flags]): boolphp

Valida un documento basado en el fichero de esquema dado.

Parámetros#

filename
La ruta al esquema.

flags
Una máscara de bits de banderas de validación de esquemas de Libxml. Actualmente el único valor admitido es LIBXML_SCHEMA_CREATE. Disponible desde Libxml 2.6.14.

Valores devueltos#

Esta función retorna true en caso de éxito o false si ocurre un error.
