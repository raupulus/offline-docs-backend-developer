Propiedades#

name
El nombre del atributo.

ownerElement
El elemento que contiene el atributo o null.

schemaTypeInfo
Aún no implementado, siempre vale null.

specified
Aún no implementado, siempre vale true.

value
El valor del atributo.

[!NOTE] Tenga en cuenta que las entidades XML se expanden cuando se define un valor. Por lo tanto, el carácter & tiene un significado especial. Establecer valor a sí mismo fallará cuando valor contiene un &. Para evitar la expansión de entidades, utilice en su lugar DOMElement::setAttribute.
