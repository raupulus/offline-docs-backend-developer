Introducción#

Un número GMP. Estos objetos admiten los operadores aritméticos, a nivel de bit y de comparación sobrecargados.

[!NOTE] No se proporciona ninguna interfaz orientada a objetos para manipular objetos GMP. Use la API de GMP procedimental.
