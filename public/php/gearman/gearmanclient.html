Introducción#

Representa una clase para conectarse a un servidor de tareas Gearman y someterle peticiones para aplicar funciones sobre los datos proporcionados. La función aplicada debe formar parte de las referenciadas por un agente Gearman y los datos procesados permanecen opacos desde el punto de vista del servidor de tareas.
