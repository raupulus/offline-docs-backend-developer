Descripción#

public EventHttp::addServerAlias(string $alias): bool
```php

Añade un alias del servidor para el objeto servidor HTTP.

## Parámetros

`alias`  
El alias a añadir.

## Valores devueltos

Esta función retorna `true` en caso de éxito o `false` si ocurre un error.
