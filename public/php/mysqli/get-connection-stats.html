mysqli::get_connection_stats

mysqli_get_connection_stats

Devuelve estadísticas sobre la conexión

Descripción#

Estilo orientado a objetos

public mysqli::get_connection_stats(): array
```php

Estilo procedimental

```php
mysqli_get_connection_stats(mysqli $mysql): array

Devuelve estadísticas sobre la conexión del cliente.

[!NOTE] Disponible solo con mysqlnd.

Parámetros#

mysql
Solo estilo procedimental: Un objeto mysqli devuelto por mysqli_connect o mysqli_init

Valores devueltos#

Devuelve un array con las estadísticas de conexión.

Ejemplos#

Ejemplo con mysqli_get_connection_stats

<?php
$link = mysqli_connect();
print_r(mysqli_get_connection_stats($link));
?>
