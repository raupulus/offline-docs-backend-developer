useRequestHeaders

main Documentación oficial Licencia MITDescargado el 2026-08-02

En esta página
  • Example#

You can use built-in useRequestHeaders composable to access the incoming request headers within your pages, components, and plugins.

// Get all request headers
const headers = useRequestHeaders()

// Get only cookie request header
const { cookie } = useRequestHeaders(['cookie'])

::tip In the browser, useRequestHeaders will return an empty object. ::

Example#

We can use useRequestHeaders to access and proxy the initial request's authorization header to any future internal requests during SSR.
