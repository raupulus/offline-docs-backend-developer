Temporal.PlainDateTime.prototype.yearOfWeek

main Documentación oficial Licencia CC-BY-SA-2.5Descargado el 2026-08-02

En esta página
  • Specifications#
  • Browser compatibility#
  • See also#

The yearOfWeek accessor property of {{jsxref("Temporal.PlainDateTime")}} instances returns an integer representing the year to be paired with the {{jsxref("Temporal/PlainDateTime/weekOfYear", "weekOfYear")}} of this date, or undefined if the calendar does not have a well-defined week system. It is calendar-dependent.

The set accessor of yearOfWeek is undefined. You cannot change this property directly.

For general information and more examples, see {{jsxref("Temporal/PlainDate/yearOfWeek", "Temporal.PlainDate.prototype.yearOfWeek")}}.
