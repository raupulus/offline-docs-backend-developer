The toLowerCase() method of {{jsxref("String")}} values returns this string converted to lower case.

{{InteractiveExample("JavaScript Demo: String.prototype.toLowerCase()", "shorter")}}

```js interactive-example const sentence = "The quick brown fox jumps over the lazy dog.";

console.log(sentence.toLowerCase()); // Expected output: "the quick brown fox jumps over the lazy dog."

## Syntax

```js-nolint
toLowerCase()

Parameters#

None.

Return value#

A new string representing the calling string converted to lower case.

Description#

The toLowerCase() method returns the value of the string converted to lower case. toLowerCase() does not affect the value of the string str itself.

Examples#

Using toLowerCase()#

console.log("ALPHABET".toLowerCase()); // 'alphabet'
