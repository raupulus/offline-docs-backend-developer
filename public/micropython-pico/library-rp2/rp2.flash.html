class Flash -- access to built-in flash storage#

This class gives access to the SPI flash memory.

In most cases, to store persistent data on the device, you'll want to use a higher-level abstraction, for example the filesystem via Python's standard file API, but this interface is useful to customise the filesystem configuration <filesystem> or implement a low-level storage system for your application.
