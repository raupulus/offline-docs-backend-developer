seaslog_get_author

Devuelve el autor de SeasLog.

## Descripción

```php
seaslog_get_author(): string
```php

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve el autor de SeasLog como string.

## Ejemplos

Ejemplo de `seaslog_get_author`

```
<?php

var_dump(seaslog_get_author());

?>

   
```php
