dba_list

Lista todos los ficheros de bases de datos DBA abiertos

## Descripción

```php
dba_list(): array
```php

`dba_list` lista todos los ficheros de bases de datos DBA abiertos.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Un array asociativo, bajo la forma `idressource => nomfichier`.
