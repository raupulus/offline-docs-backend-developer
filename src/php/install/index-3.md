## Instalación en un sistema macOS

PHP estaba incluido con macOS en las versiones 10 y 11, pero ya no está incluido desde la versión macOS 12 (Monterey). La instalación en las versiones recientes requiere ya sea el uso de paquetes provenientes de fuentes de terceros, ya sea la compilación a partir del código fuente.
