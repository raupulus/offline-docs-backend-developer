HRTime\PerformanceCounter::getTicks

Ticks actuales desde el sistema

## Descripción

```php
public static HRTime\PerformanceCounter::getTicks(): int
```php

Devuelve el recuento de ticks.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve un `int` que indica el recuento de ticks.
