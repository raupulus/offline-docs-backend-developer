IntlTimeZone::countEquivalentIDs

intltz_count_equivalent_ids

Obtiene el número de IDs en el grupo de equivalencia que incluye el ID proporcionado

## Descripción

Estilo orientado a objetos (método):

```php
public static IntlTimeZone::countEquivalentIDs(string $timezoneId): int
```php

Estilo procedimental:

```php
intltz_count_equivalent_ids(string $timezoneId): int
```

> [!WARNING]
> Esta función está actualmente no documentada; solo la lista de sus argumentos está disponible.

## Parámetros

`timezoneId`
