IntlTimeZone::getEquivalentID

intltz_get_equivalent_id

Obtiene un identificador de un grupo de equivalencia que incluye el identificador proporcionado

## Descripción

Estilo orientado a objetos (método):

```php
public static IntlTimeZone::getEquivalentID(string $timezoneId, int $offset): string
```php

Estilo procedimental:

```php
intltz_get_equivalent_id(string $timezoneId, int $offset): string
```

> [!WARNING]
> Esta función está actualmente no documentada; solo la lista de sus argumentos está disponible.

## Parámetros

`timezoneId`  

`offset`
