IntlTimeZone::getErrorCode

## Descripción

Estilo orientado a objetos (método):

```php
public IntlTimeZone::getErrorCode(): int
```php

Estilo procedimental:

```php
intltz_get_error_code(IntlTimeZone $timezone): int
```

> [!WARNING]
