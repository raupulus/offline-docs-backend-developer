UConverter::setSourceEncoding

Define el conjunto de caracteres de la fuente

## Descripción

```php
public UConverter::setSourceEncoding(string $encoding): bool
```php

Este método permite establecer el conjunto de caracteres para la fuente de datos.

> [!WARNING]
> Esta función está actualmente no documentada; solo la lista de sus argumentos está disponible.

## Parámetros

`encoding`  
El `encoding` especifica el conjunto de caracteres a utilizar.

## Valores devueltos

Este método devuelve un valor booleano que indica si la operación fue exitosa.
