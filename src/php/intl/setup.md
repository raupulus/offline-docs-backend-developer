## Instalación/Configuración

## Requisitos

Para compilar esta extensión, es necesario instalar la biblioteca [ICU](https://icu.unicode.org/) versión 4.0.0 o más reciente. A partir de PHP 7.4.0 se requiere ICU 50.1 o más reciente.
