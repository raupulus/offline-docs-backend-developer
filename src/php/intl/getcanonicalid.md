IntlTimeZone::getCanonicalID

intltz_get_canonical_id

Obtiene el identificador del huso horario del sistema o el identificador normalizado del huso horario personalizado para el ID del huso horario proporcionado

## Descripción

Estilo orientado a objetos (método):

```php
public static IntlTimeZone::getCanonicalID(string $timezoneId, [bool $isSystemId]): string
```php

Estilo procedimental:

```php
intltz_get_canonical_id(string $timezoneId, [bool $isSystemId]): string
```

> [!WARNING]
> Esta función está actualmente no documentada; solo la lista de sus argumentos está disponible.

## Parámetros

`timezoneId`  

`isSystemId`
