Spoofchecker::setAllowedLocales

Locales a utilizar durante la verificación

## Descripción

```php
public Spoofchecker::setAllowedLocales(string $locales): void
```php

Este método permite especificar las locales que deben ser consideradas válidas durante la verificación.

> [!WARNING]
> Esta función está actualmente no documentada; solo la lista de sus argumentos está disponible.

## Parámetros

`locales`  
Un string que contiene las locales permitidas, separadas por comas.

## Valores devueltos

Este método no devuelve ningún valor.
