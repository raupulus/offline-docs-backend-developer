Dom\ParentNode::querySelectorAll

Devuelve una colección de elementos que coinciden con los selectores CSS

## Descripción

```php
public Dom\ParentNode::querySelectorAll(string $selectors): Dom\NodeList
```php

Devuelve una colección de elementos que coinciden con los selectores CSS especificados en `selectors`.

## Valores devueltos

Devuelve una colección estática de elementos que coinciden con los selectores CSS especificados en `selectors`.
