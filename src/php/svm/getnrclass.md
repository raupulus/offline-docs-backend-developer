SVMModel::getNrClass

Devuelve el número de clases utilizadas para entrenar el modelo

## Descripción

```php
public SVMModel::getNrClass(): integer
```php

Devuelve el número de clases utilizadas para entrenar el modelo; devolverá 2 para una sola clase y para los modelos de regresión.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve el número de clases, en forma de un entero.
