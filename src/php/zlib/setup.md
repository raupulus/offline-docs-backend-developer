## Instalación/Configuración

## Requisitos

Este módulo usa las funciones de [zlib](http://www.zlib.net/) por Jean-loup Gailly y Mark Adler. A partir de PHP 8.4.0, la versión mínima de zlib requerida es 1.2.11. Antes de PHP 8.4.0, la versión mínima de zlib requerida era 1.2.0.4.

## Tipos de recursos

Esta extensión define un recurso de archivo puntero retornado por `gzopen`. Antes de PHP 8.0.0, `zlib.deflate` y `zlib.inflate` recursos también estaban definidos.
