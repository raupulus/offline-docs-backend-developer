XMLWriter::toMemory

Crear un nuevo

XMLWriter

utilizando la memoria para la salida de cadena

## Descripción

```php
public static XMLWriter::toMemory(): static
```php

Crear un nuevo `XMLWriter` utilizando la memoria para la salida de cadena.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve un `XMLWriter`.
