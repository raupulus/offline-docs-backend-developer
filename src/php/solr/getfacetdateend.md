SolrQuery::getFacetDateEnd

Devuelve el valor del parámetro facet.date.end

## Descripción

```php
public SolrQuery::getFacetDateEnd([string $field_override]): string
```php

Devuelve el valor del parámetro facet.date.end. Este método acepta una sobrescritura opcional de campos

## Parámetros

`field_override`  
El nombre del campo

## Valores devueltos

Devuelve una cadena en caso de éxito y `null` si no se estableció
