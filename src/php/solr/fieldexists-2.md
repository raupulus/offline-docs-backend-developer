SolrInputDocument::fieldExists

Comprueba si existe un campo

## Descripción

```php
public SolrInputDocument::fieldExists(string $fieldName): bool
```php

Comprueba si existe un campo

## Parámetros

`fieldName`  
Nombre del campo.

## Valores devueltos

Devuelve `true` si se encontró el campo y `false` si no se encontró.
