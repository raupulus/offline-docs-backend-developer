SolrCollapseFunction::setField

Define el campo sobre el cual se realiza la reducción

## Descripción

```php
public SolrCollapseFunction::setField(string $fieldName): SolrCollapseFunction
```php

El campo sobre el cual se realiza la reducción. Para reducir un resultado, el tipo de campo debe ser un string, un integer o un float.

## Parámetros

`fieldName`  

## Valores devueltos

`SolrCollapseFunction`
