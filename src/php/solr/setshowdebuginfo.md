SolrQuery::setShowDebugInfo

Bandera para mostrar información de depuración

## Descripción

```php
public SolrQuery::setShowDebugInfo(bool $flag): SolrQuery
```php

Si mostrar o no información de depuración

## Parámetros

`flag`  
Si mostrar o no información de depuración. `true` o `false`

## Valores devueltos

Devuelve el objeto SolrQuery actual, si se usó el valor de retorno.
