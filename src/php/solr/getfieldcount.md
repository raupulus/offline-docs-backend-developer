SolrDocument::getFieldCount

Devuelve el número de campos de este documento

## Descripción

```php
public SolrDocument::getFieldCount(): int
```php

Devuelve el número de campos de este documento. Los campo multi valor sólo se cuentan una vez.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve un entero en caso de éxito y `false` en caso de fallo.
