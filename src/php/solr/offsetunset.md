SolrDocument::offsetUnset

Elimina un campo

## Descripción

```php
public SolrDocument::offsetUnset(string $fieldName): void
```php

Elimina un campo del documento.

## Parámetros

`fieldName`  
El nombre del campo.

## Valores devueltos

No se devuelve ningún valor.
