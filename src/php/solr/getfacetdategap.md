SolrQuery::getFacetDateGap

Devuelve el valor del parámetro facet.date.gap

## Descripción

```php
public SolrQuery::getFacetDateGap([string $field_override]): string
```php

Devuelve el valor del parámetro facet.date.gap. Acepta una sobrescritura opcional de campos

## Parámetros

`field_override`  
El nombre del campo

## Valores devueltos

Devuelve una cadena en caso de éxito y `null` si no se estabelció
