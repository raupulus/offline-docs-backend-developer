http_clear_last_response_headers

Borra los encabezados de respuesta HTTP almacenados

## Descripción

```php
http_clear_last_response_headers(): void
```php

Borra los encabezados de respuesta HTTP almacenados mediante [la envoltura HTTP](#wrappers.http).

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

No se retorna ningún valor.
