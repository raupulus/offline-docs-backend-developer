## Instalación/Configuración

## Requisitos

Para acceder a cualquiera de las bases de datos soportadas se necesitan tener instaladas las bibliotecas requeridas.

## Tipos de recursos

Antes de PHP 8.4.0, esta extensión definía dos tipos de recursos: un identificador de conexión ODBC y un identificador de resultado ODBC.
