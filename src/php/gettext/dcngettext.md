dcngettext

Versión plural de dcgettext

## Descripción

```php
dcngettext(string $domain, string $singular, string $plural, int $count, int $category): string
```php

Permite reemplazar el dominio actual para una búsqueda simple en plural de un mensaje.

## Parámetros

`domain`  
El dominio

`singular`  

`plural`  

`count`  

`category`  

## Valores devueltos

Una `string` en caso de éxito.
