GearmanClient::setOptions

Define las opciones del cliente

## Descripción

```php
public GearmanClient::setOptions(int $option): bool
```php

Define una o varias opciones del cliente.

## Parámetros

`option`  
Las opciones a definir.

## Valores devueltos

Retorna siempre `true`.
