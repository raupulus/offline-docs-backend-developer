GearmanJob::workload

Obtiene la carga de trabajo

## Descripción

```php
public GearmanJob::workload(): string
```php

Obtiene la carga para este trabajo. Son los datos serializados a analizar por el agente.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Los datos serializados.
