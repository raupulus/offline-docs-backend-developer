GearmanClient::context

Recupera el contexto de la aplicación

## Descripción

```php
public GearmanClient::context(): string
```php

Recupera el contexto de la aplicación previamente definido con el método GearmanClient::setContext.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Los datos de contexto idénticos a los definidos con la función GearmanClient::setContext
