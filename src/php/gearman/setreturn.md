GearmanJob::setReturn

Define un valor de retorno

## Descripción

```php
public GearmanJob::setReturn(int $gearman_return_t): bool
```php

Define un valor de retorno para este trabajo, indicando la forma en que terminó este trabajo.

## Parámetros

`gearman_return_t`  
Un valor de retorno válido de Gearman.
