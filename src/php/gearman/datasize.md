GearmanTask::dataSize

Obtiene el tamaño de los datos devueltos

## Descripción

```php
public GearmanTask::dataSize(): int
```php

Devuelve el tamaño de los datos devueltos de una tarea.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

El tamaño de los datos, o `false` si no hay datos.
