## Introducción

Un número GMP. Estos objetos admiten los operadores [aritméticos](#language.operators.arithmetic), [a nivel de bit](#language.operators.bitwise) y [de comparación](#language.operators.comparison) sobrecargados.

> [!NOTE]
> No se proporciona ninguna interfaz orientada a objetos para manipular objetos `GMP`. Use la [API de GMP procedimental](#book.gmp).
