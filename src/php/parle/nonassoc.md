Parle\Parser::nonassoc

Declara un token sin asociatividad

## Descripción

```php
public Parle\Parser::nonassoc(string $tok): void
```php

Declara un token, que solo puede aparecer una vez en la línea.

## Parámetros

`tok`  
El nombre del token.

## Valores devueltos

No se retorna ningún valor.
