Parle\RLexer::reset

Reinicializa el analizador léxico

## Descripción

```php
public Parle\RLexer::reset(int $pos): void
```php

Reinicializa el analizador léxico pasando opcionalmente la posición deseada.

## Parámetros

`pos`  
La posición para reinicializar.

## Valores devueltos

No se retorna ningún valor.
