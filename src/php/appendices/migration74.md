## Migración de PHP 7.3.x a PHP 7.4.x

Esta nueva versión menor trae consigo una serie de [nuevas características](#migration74.new-features) y [algunas incompatibilidades](#migration74.incompatible) que debe ser probado antes de cambiar las versiones de PHP en los entornos de producción.

Véase también las guías de migración entre las diferentes versiones de PHP [7.0.x](#migration70), [7.1.x](#migration71), [7.2.x](#migration72) y [7.3.x](#migration73).
