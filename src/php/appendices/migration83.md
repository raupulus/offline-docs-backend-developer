## Migración de PHP 8.2.x a PHP 8.3.x

Esta nueva versión menor aporta un cierto número de [nuevas funcionalidades](#migration83.new-features) y [algunas incompatibilidades](#migration83.incompatible) que deberían ser probadas antes de cambiar de versión de PHP en entornos de producción.

Véase también las guías de migración entre las diferentes versiones de PHP [7.1.x](#migration71), [7.2.x](#migration72), [7.3.x](#migration73), [7.4.x](#migration74), [8.0.x](#migration80), [8.1.x](#migration81), [8.2.x](#migration82).
