## Migración de PHP 7.2.x a PHP 7.3.x

Esta nueva versión menor trae consigo una serie de [nuevas características](#migration73.new-features) y unas [pocas incompatibilidades](#migration73.incompatible) que se deben probar antes de cambiar las versiones de PHP en entornos de producción.

Véase también las guías de migración entre las diferentes versiones de PHP [7.0.x](#migration70), [7.1.x](#migration71) y [7.2.x](#migration72).
