## Migración de PHP 7.1.x a PHP 7.2.x

Esta versión menor viene con varias [características nuevas](#migration72.new-features) y [algunas incompatibilidades](#migration72.incompatible) que deberían ser probadas antes de cambiar de versión de PHP en entornos de producción.

Véase también las guías de migración entre las diferentes versiones de PHP [7.0.x](#migration70) y [7.1.x](#migration71).
