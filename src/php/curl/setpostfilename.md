CURLFile::setPostFilename

Define el nombre del fichero para POST

## Descripción

```php
public CURLFile::setPostFilename(string $posted_filename): void
```php

## Parámetros

`posted_filename`  
Nombre del fichero a utilizar para los datos POST.

## Valores devueltos

No se retorna ningún valor.
