## Introducción

Un `ParseError` se lanza cuando ocurre un error al analizar código de PHP, tal como cuando se llama a `eval`.

> [!NOTE]
> `ParseError` extiende `CompileError` a partir de PHP 7.3.0. Anteriormente, extendía `Error`.
