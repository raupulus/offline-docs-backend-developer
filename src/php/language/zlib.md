Opciones de contexto Zlib

Lista de opciones de contexto Zlib

## Descripción

Las opciones de contexto Zlib están disponibles para las envolturas `zlib`.

## Opciones

`level`  
Permite especificar el nivel de compresión`(0` - `9`).
