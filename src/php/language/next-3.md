Iterator::next

Avanza al siguiente elemento

## Descripción

```php
public Iterator::next(): void
```php

Avanza la posición actual al siguiente elemento.

> [!NOTE]
> El método es llamado *después* de cada [`foreach`](#control-structures.foreach) loop.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

El valor devuelto es ignorado.
