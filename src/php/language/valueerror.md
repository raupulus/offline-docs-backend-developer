## Introducción

Una `ValueError` se lanza cuando el tipo de un argumento es correcto pero su valor es incorrecto. Por ejemplo, si se pasa un entero negativo cuando la función espera un entero positivo, o si se pasa una cadena o un array vacío cuando la función espera que no esté vacío.
