EventHttp::setTimeout

Define el tiempo máximo de espera para una petición HTTP

## Descripción

```php
public EventHttp::setTimeout(int $value): void
```php

Define el tiempo máximo de espera para una petición HTTP.

## Parámetros

`value`  
El tiempo máximo de espera, en segundos.

## Valores devueltos

No se retorna ningún valor.
