EventHttpConnection::setTimeout

Define el tiempo límite máximo para la conexión

## Descripción

```php
public EventHttpConnection::setTimeout(int $timeout): void
```php

Define el tiempo límite máximo para la conexión.

## Parámetros

`timeout`  
El tiempo límite máximo, en segundos.

## Valores devueltos

No se retorna ningún valor.
