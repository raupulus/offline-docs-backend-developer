EventHttpRequest::getCommand

Devuelve el comando de la petición (método)

## Descripción

```php
public EventHttpRequest::getCommand(): void
```php

Devuelve el comando de la petición; una de las constantes [ `EventHttpRequest::CMD_*` ](#eventhttprequest.constants).

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve el comando de la petición; una de las constantes [ `EventHttpRequest::CMD_*` ](#eventhttprequest.constants).
