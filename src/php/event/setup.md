## Instalación/Configuración

## Requisitos

Esta extensión requiere la biblioteca [libevent](http://libevent.org/). La mayoría de las distribuciones modernas proporcionan paquetes para libevent.

Las funcionalidades OpenSSL requieren la biblioteca [OpenSSL](http://www.openssl.org/).

## Instalación

Esta extensión [PECL](https://pecl.php.net/) no está integrada en PHP.

Información sobre la instalación de estas extensiones PECL puede ser encontrada en el capítulo del manual titulado [Instalación de extensiones PECL](#install.pecl). Otra información como notas sobre nuevas versiones, descargas, fuentes de ficheros, información sobre los mantenedores así como un CHANGELOG, pueden ser encontradas aquí: <https://pecl.php.net/package/event>.
