FilesystemIterator::getFlags

Lee las opciones activadas

## Descripción

```php
public FilesystemIterator::getFlags(): int
```php

Lee las opciones activadas, tal como fueron configuradas con FilesystemIterator::\_\_construct o FilesystemIterator::setFlags.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

El valor de las opciones configuradas.

## Véase también

FilesystemIterator::\_\_construct, FilesystemIterator::setFlags
