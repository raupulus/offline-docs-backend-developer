RecursiveTreeIterator::callHasChildren

Comprobar si tiene hijos

## Descripción

```php
public RecursiveTreeIterator::callHasChildren(): bool
```php

Se llama para cada elemento para comprobar si tiene hijos o no.

> [!WARNING]
> Esta función está actualmente no documentada; solo la lista de sus argumentos está disponible.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

`true` si tiene hijos, en caso contrario `false`.
