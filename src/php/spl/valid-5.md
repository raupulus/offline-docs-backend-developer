EmptyIterator::valid

Verifica si el elemento actual es válido

## Descripción

```php
public EmptyIterator::valid(): false
```php

Verifica si el elemento actual es válido.

> [!NOTE]
> El `EmptyIterator` siempre está vacío y nunca tendrá un valor válido. El valor de retorno siempre es `false`.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

`false`
