SplFixedArray::valid

Comprueba si el array contiene más elementos

## Descripción

```php
public SplFixedArray::valid(): bool
```php

Comprueba si el array contiene más elementos.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve `true` si el array contiene más elementos, en caso contrario `false`.
