OuterIterator::getInnerIterator

Devuelve el iterador interno para la entrada actual

## Descripción

```php
public OuterIterator::getInnerIterator(): Iterator
```php

Devuelve el iterador interno para la entrada actual.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve el iterador interno para la entrada actual si existe, `null` en caso contrario.
