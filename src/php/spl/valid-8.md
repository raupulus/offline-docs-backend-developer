LimitIterator::valid

Verifica si el elemento actual es válido

## Descripción

```php
public LimitIterator::valid(): bool
```php

Verifica si el elemento actual es válido.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Esta función retorna `true` en caso de éxito o `false` si ocurre un error.
