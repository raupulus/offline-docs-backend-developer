OCICollection::size

Devuelve el tamaño de una colección Oracle

## Descripción

```php
public OCICollection::size(): int
```php

Devuelve el tamaño de una colección Oracle.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve el número de elementos de la colección, o `false` en caso de error.
