oci_internal_debug

Activa o desactiva la salida de depuración interna

## Descripción

```php
oci_internal_debug(bool $onoff): void
```php

Activa o desactiva la salida de depuración interna.

## Parámetros

`onoff`  
Establezca este valor a `false` para desactivar la salida de depuración o a `true` para activarla.

## Valores devueltos

No se retorna ningún valor.

## Notas

> [!NOTE]
> Esta función fue eliminada en PHP 8 y PECL OCI8 3.0.
