## Introducción

Lanzada cuando una de las clases Date/Hora no ha sido correctamente inicializada.

Dado que las clases Date/Hora no son finales, estas clases pueden ser heredadas. Cuando el constructor padre no es llamado, este error es lanzado. Siempre es un error de programación.
