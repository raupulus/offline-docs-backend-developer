## Instalación

No hay instalación necesaria para usar estas funciones, son parte del núcleo de PHP.

> [!NOTE]
> La última versión de la base de datos de los husos horarios puede ser instalada mediante el paquete PECL [timezonedb](https://pecl.php.net/get/timezonedb).
