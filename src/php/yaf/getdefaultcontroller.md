Yaf_Dispatcher::getDefaultController

Recupera el nombre del controlador predeterminado

## Descripción

```php
public Yaf_Dispatcher::getDefaultController(): string
```php

obtiene el nombre del controlador predeterminado

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

`string`, nombre del controlador por defecto, por defecto es "Index"
