Imagick::getImageAttribute

Obtiene un atributo nombrado

> [!WARNING]
> Esta función está *DEPRECADA* a partir de Imagick 3.4.4. Depender de esta funcionalidad está fuertemente desaconsejado.

## Descripción

```php
public Imagick::getImageAttribute(string $key): string
```php

Obtiene un atributo nombrado.

## Parámetros

`key`  
La clave del atributo a obtener.
