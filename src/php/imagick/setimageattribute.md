Imagick::setImageAttribute

Define un atributo de imagen

> [!WARNING]
> Esta función está *DEPRECADA* a partir de Imagick 3.4.4. Depender de esta funcionalidad está fuertemente desaconsejado.

## Descripción

```php
public Imagick::setImageAttribute(string $key, string $value): bool
```php

Define un atributo de imagen.

## Parámetros

`key`  

`value`  

## Valores devueltos

Devuelve `true` en caso de éxito.
