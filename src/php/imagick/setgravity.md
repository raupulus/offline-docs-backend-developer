Imagick::setGravity

Establece la gravedad

## Descripción

```php
public Imagick::setGravity(int $gravity): bool
```php

Establece la propiedad gravedad global para el objeto Imagick. Este método solo está disponible si Imagick ha sido compilado con ImageMagick versión 6.4.0 o superior.

## Parámetros

`gravity`  
La propiedad gravedad. Consulte esta lista de [constantes de gravedad](#imagick.constants.gravity).

## Valores devueltos

No se retorna ningún valor.
