Imagick::getOption

Devuelve un valor asociado con la clave especificada

## Descripción

```php
public Imagick::getOption(string $key): string
```php

Devuelve un valor asociado dentro del objeto para una clave especificada.

## Parámetros

`key`  
El nombre de la opción

## Valores devueltos

Devuelve un valor asociado con una varita mágica y la clave especificada.

## Errores/Excepciones

Lanza una ImagickException en caso de error.
