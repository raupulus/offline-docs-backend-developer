Imagick::getRegistry

Obtiene un elemento de StringRegistry

## Descripción

```php
public static Imagick::getRegistry(string $key): string
```php

Obtiene la entrada StringRegistry para la clave nombrada o false si no está definida.

## Parámetros

`key`  
La entrada a obtener.
