ImagickDraw::getStrokeLineCap

Devuelve la forma a utilizar para dibujar los extremos de subrutas

## Descripción

```php
public ImagickDraw::getStrokeLineCap(): int
```php

> [!WARNING]
> Esta función está actualmente no documentada; solo la lista de sus argumentos está disponible.

Devuelve la forma a utilizar para dibujar los extremos de subrutas.

## Valores devueltos

Devuelve una constante [LINECAP](#imagick.constants.linecap) (`imagick::LINECAP_*`), o 0 si los extremos de líneas no están configurados.
