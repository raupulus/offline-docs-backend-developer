Imagick::hasPreviousImage

Verifica si un objeto tiene una imagen anterior

## Descripción

```php
public Imagick::hasPreviousImage(): bool
```php

Devuelve `true` si el objeto tiene una imagen anterior, para poder revisar la lista en orden inverso.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve `true` si el objeto tiene una imagen anterior, y `false` en caso contrario.
