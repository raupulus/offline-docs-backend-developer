Imagick::readImages

Lee una imagen a partir de un array de nombres de ficheros

## Descripción

```php
public Imagick::readImages(array $filenames): bool
```php

Lee una imagen a partir de un array de nombres de ficheros. Todas las imágenes se almacenan en un solo objeto Imagick.

## Parámetros

`filenames`  

## Valores devueltos

Devuelve `true` en caso de éxito.
