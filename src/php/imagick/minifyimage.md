Imagick::minifyImage

Redimensiona una imagen proporcionalmente para reducirla a la mitad de tamaño

## Descripción

```php
public Imagick::minifyImage(): bool
```php

Esta función es un atajo práctico para redimensionar una imagen proporcionalmente para reducirla a la mitad de tamaño.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve `true` en caso de éxito.
