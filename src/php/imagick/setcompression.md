Imagick::setCompression

Configura el tipo de compresión del objeto

## Descripción

```php
public Imagick::setCompression(int $compression): bool
```php

Configura el tipo de compresión del objeto.

## Parámetros

`compression`  
El tipo de compresión. Ver las constantes [Imagick::COMPRESSION\_\*](#imagick.constants).

## Valores devueltos

Devuelve `true` en caso de éxito.
