Imagick::getGravity

Obtiene la gravedad

## Descripción

```php
public Imagick::getGravity(): int
```php

Obtiene la propiedad global de gravedad para el objeto Imagick. Este método solo está disponible si Imagick ha sido compilado con ImageMagick versión 6.4.0 o superior.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve la propiedad de gravedad. Consúltese la lista de [constantes de gravedad](#imagick.constants.gravity).
