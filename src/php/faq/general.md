## Información general

Esta sección contiene las preguntas más generales sobre PHP: Qué es y qué hace.

**Q:** ¿Qué es PHP?

**A:** Según el [prefacio del manual](#preface):

PHP es un lenguaje de «scripting» que puede ser embebido en HTML. Gran parte de su sintaxis se toma prestada de C, Java y Perl con un par de características específicas propias de PHP. El objetivo del lenguaje es permitir a los desarrolladores web escribir con rapidez páginas generadas dinámicamente.

**Q:** ¿Qué significa PHP?

**A:** PHP significa *PHP: Hypertext Preprocessor*. Esto confunde a mucha gente porque la primera palabra del acrónimo es el acrónimo mismo. Este tipo de acrónimo se denomina 'acrónimo recursivo'. Para más información, los curiosos pueden visitar [El Diccionario de Informática On-Line Gratuito](http://foldoc.org/) ó la [entrada de acrónimo recursivo en Wikipedia](http://en.wikipedia.org/wiki/Recursive_acronym) (ambos en inglés).

**Q:** ¿Cuál es la relación entre las versiones?

**A:** PHP/FI 2.0 es una versión de PHP antigua y sin soporte. PHP 3 es el sucesor de PHP/FI 2.0 y es mucho mejor. PHP 8 es la generación actual de PHP, la cual emplea el Motor Zend 4 que, entre otras cosas, ofrece muchas características adicionales de [POO](#language.oop5).

**Q:** ¿Puedo usar varias versiones de PHP al mismo tiempo?

**A:** Sí. Vea el fichero `INSTALL` que se incluye en la distribución del código fuente de PHP.

**Q:** ¡Creo que he encontrado un error! ¿A quién debo informar?

**A:** Debería ir a la Base de datos de errores de PHP y asegurarse de que no se trate de un error ya descubierto. Si no lo encuentra en la Base de datos, use el formulario de notificación para informar del error. Es importante que utilice la Base de datos de errores en vez de solamente enviar un correo electrónico a una de las listas de correo, ya que así al error se le asignará un número de seguimiento, pudiendo volver luego y comprobar el estado de dicho error. La Base de datos de errores de PHP se encuentra en <https://github.com/php/php-src/issues>.
