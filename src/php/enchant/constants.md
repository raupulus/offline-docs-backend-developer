## Constantes predefinidas

`LIBENCHANT_VERSION` (`string`)  
La versión de libenchant. Disponible a partir de PHP 8.0.0.

`ENCHANT_MYSPELL` (`int`)  
Tipo de diccionario para MySpell. Utilizado con `enchant_broker_get_dict_path` y `enchant_broker_set_dict_path`. Deprecado a partir de PHP 8.0.0.

`ENCHANT_ISPELL` (`int`)  
Tipo de diccionario para Ispell. Utilizado con `enchant_broker_get_dict_path` y `enchant_broker_set_dict_path`. Deprecado a partir de PHP 8.0.0.
