eio_set_max_poll_time

Establecer el tiempo máximo de monitorización

## Descripción

```php
eio_set_max_poll_time(float $nseconds): void
```php

La monitorización se detiene si toma más de `nseconds` segundos.

## Parámetros

`nseconds`  
El número de segundos

## Valores devueltos

No se retorna ningún valor.
