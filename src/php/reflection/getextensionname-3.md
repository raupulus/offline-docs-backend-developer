ReflectionFunctionAbstract::getExtensionName

Obtiene el nombre de la extensión

## Descripción

```php
public ReflectionFunctionAbstract::getExtensionName(): string
```php

Obtiene el nombre de la extensión.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

El nombre de la extensión que define la función, o `false` para las funciones definidas por el usuario.
