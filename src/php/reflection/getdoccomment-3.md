ReflectionFunctionAbstract::getDocComment

Obtiene un comentario

## Descripción

```php
public ReflectionFunctionAbstract::getDocComment(): string
```php

Obtiene un comentario desde una función.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

El comentario, si existe, `false` en caso contrario.
