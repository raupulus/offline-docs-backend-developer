ReflectionAttribute::getTarget

Devuelve el objetivo del atributo como máscara de bits

## Descripción

```php
public ReflectionAttribute::getTarget(): int
```php

Devuelve el objetivo del atributo como máscara de bits.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Obtiene el objetivo del atributo en forma de máscara de bits de las [`constantes Attribute::TARGET_*`](#attribute.constants).
