fdf_header

Emite las cabeceras HTTP específicas de FDF

## Descripción

```php
fdf_header(): void
```php

fdf_header es una función de conveniencia, para emitir las cabeceras HTTP específicas de FDF. Permite enviar el tipo `Content-type:` con el valor `application/vnd.fdf`.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

No se retorna ningún valor.
