Ev::verify

Efectúa verificaciones internas de consistencia (para la depuración)

## Descripción

```php
final public static Ev::verify(): void
```php

Efectúa verificaciones internas de consistencia (para la depuración de *libev*) y finaliza el programa si se encuentra una estructura de datos corrompida.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

No se retorna ningún valor.
