Ev::time

Devuelve el tiempo actual desde la época Unix

## Descripción

```php
final public static Ev::time(): float
```php

Devuelve el tiempo actual desde la época Unix. Se recomienda utilizar el método Ev::now.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve el tiempo actual, en número de segundos, desde la época Unix.
