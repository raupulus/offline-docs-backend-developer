EvEmbed::set

Configura el watcher

## Descripción

```php
public EvEmbed::set(object $other): void
```php

Configura el watcher para utilizar el objeto `other` del bucle de eventos.

## Parámetros

`other`  
Idéntico al argumento del método EvEmbed::\_\_construct

## Valores devueltos

No se retorna ningún valor.
