## Instalación/Configuración

## Requisitos

Este módulo usa las funciones de la librería [bzip2 ](https://www.sourceware.org/bzip2/) por Julian Seward. Este módulo requiere bzip2/libbzip2 version \>= 1.0.x.

## Tipos de recursos

Esta extensión define un tipo de recurso: apunta a un archivo identificando el fichero bz2 a trabajar.
