ZMQSocket::getPersistentId

Obtener el ID de persistencia

## Descripción

```php
public ZMQSocket::getPersistentId(): string
```php

Devuelve el ID de persistencia del socket.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve el ID de persistencia asignado al objeto, y `null` si el socket no es persistente.
