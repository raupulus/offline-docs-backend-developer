ZMQPoll::count

Contar los elementos del conjunto de sondeo

## Descripción

```php
public ZMQPoll::count(): int
```php

Cuenta los elementos del conjunto de sondeo.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve un `int` que representa la cantidad de elementos del conjunto de sondeo.
