sodium_crypto_stream_keygen

Genera una clave de cifrado aleatoria para sodium_crypto_stream

## Descripción

```php
sodium_crypto_stream_keygen(): string
```php

Genera una clave para ser utilizada con `sodium_crypto_stream` y `sodium_crypto_stream_xor`.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

La clave de cifrado (256 bits).
