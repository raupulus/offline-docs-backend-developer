sodium_crypto_generichash_keygen

Genera una clave de hash genérico aleatoria

## Descripción

```php
sodium_crypto_generichash_keygen(): string
```php

Genera una clave aleatoria para su uso con la API de hash genérico.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Una clave aleatoria de 256 bits.
