sodium_crypto_aead_aegis128l_keygen

Genera una clave AEGIS-128L aleatoria

## Descripción

```php
sodium_crypto_aead_aegis128l_keygen(): string
```php

Genera una clave aleatoria de 128 bits para ser utilizada con `sodium_crypto_aead_aegis128l_encrypt` y `sodium_crypto_aead_aegis128l_decrypt`.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve una clave aleatoria de 128 bits.
