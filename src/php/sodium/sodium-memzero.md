sodium_memzero

Sobrescribe una string con caracteres NUL

## Descripción

```php
#[\SensitiveParameter] sodium_memzero(string $string): void
```php

`sodium_memzero` reemplaza por ceros la string pasada por referencia.

## Parámetros

`string`  
String.

## Valores devueltos

No se retorna ningún valor.
