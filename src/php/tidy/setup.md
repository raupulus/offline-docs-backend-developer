## Instalación/Configuración

## Requisitos

Para utilizar Tidy, debe disponerse de la biblioteca libtidy, que está disponible en la [página de inicio de tidy](http://tidy.sourceforge.net/). A partir de PHP 7.1.0, el sucesor consciente de HTML5 [libtidy5](http://www.html-tidy.org/) puede ser utilizado alternativamente. A partir de PHP 7.3.0, otra opción es utilizar [libtidyp](https://github.com/petdance/tidyp).
