## Instalación/Configuración

## Requisitos

*Modificar constantes, funciones, clases y métodos* así como las *superglobales personalizadas* funciona con todas las versiones de PHP 7. No se requieren exigencias especiales.

## Instalación

Esta extensión [PECL](https://pecl.php.net/) no está integrada en PHP.

Información sobre la instalación de estas extensiones PECL puede ser encontrada en el capítulo del manual titulado [Instalación de extensiones PECL](#install.pecl). Otra información como notas sobre nuevas versiones, descargas, fuentes de ficheros, información sobre los mantenedores así como un CHANGELOG, pueden ser encontradas aquí: <https://pecl.php.net/package/runkit7>.

Los binarios Windows (los ficheros DLL) para esta extensión PECL están disponibles en el sitio web PECL.
