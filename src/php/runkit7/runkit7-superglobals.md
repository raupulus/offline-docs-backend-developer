runkit7_superglobals

Devuelve un array indexado numéricamente de las superglobales registradas

## Descripción

```php
runkit7_superglobals(): array
```php

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve un array indexado numéricamente de las superglobales registradas. Es decir, \_GET, \_POST, \_REQUEST, \_COOKIE, \_SESSION, \_SERVER, \_ENV, \_FILES
