RRDCreator::save

Guarda la base de datos RRD en un archivo

## Descripción

```php
public RRDCreator::save(): bool
```php

Guarda la base de datos RRD en un archivo, cuyo nombre es definido por RRDCreator::\_\_construct.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Esta función retorna `true` en caso de éxito o `false` si ocurre un error.
