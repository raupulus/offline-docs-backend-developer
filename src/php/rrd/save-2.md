RRDGraph::save

Guarda el resultado de una consulta en una imagen

## Descripción

```php
public RRDGraph::save(): array
```php

Guarda el resultado de una consulta de base de datos RRD en una imagen definida por el método RRDGraph::\_\_construct.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve un array que contiene información sobre la imagen generada, o `false` si ocurre un error.
