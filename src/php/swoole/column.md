Swoole\Table::column

Define el tipo de datos y el tamaño de las columnas.

## Descripción

```php
public Swoole\Table::column(string $name, string $type, [int $size]): bool
```php

## Parámetros

`name`  
Especifica el nombre del campo.

`type`  
Especifica el tipo del campo.

`size`  
Especifica el tamaño del campo.
