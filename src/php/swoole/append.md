Swoole\Buffer::append

Añade la string o los datos binarios al final del buffer de memoria y devuelve el nuevo tamaño de la memoria asignada.

## Descripción

```php
public Swoole\Buffer::append(string $data): int
```php

## Parámetros

`data`  
La string o los datos binarios a añadir al final del buffer de memoria.

## Valores devueltos

El nuevo tamaño del buffer de memoria.
