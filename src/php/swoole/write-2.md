Swoole\Buffer::write

Escribe datos en el buffer de memoria. La memoria asignada para el buffer no será modificada.

## Descripción

```php
public Swoole\Buffer::write(int $offset, string $data): void
```php

## Parámetros

`offset`  
El desplazamiento.

`data`  
Los datos a escribir en el buffer de memoria.
