Pdo\Firebird::getApiVersion

Devuelve la versión de la API

## Descripción

```php
public static Pdo\Firebird::getApiVersion(): int
```php

Devuelve la versión de la API Firebird tal como está definida por la constante C `FB_API_VER` en `ibase.h`.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve la API Firebird como `int`.
