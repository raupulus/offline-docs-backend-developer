## Instalación/Configuración

## Requisitos

Este módulo utiliza las funciones de la biblioteca [zlib](http://www.zlib.net/) para soportar la compresión de datos a la volée. Zlib es por lo tanto requerido para instalar este módulo.

## Tipos de recursos

Existe una única recurso utilizado por el módulo `Memcache`: es el enlace identificador que representa la conexión del servidor de caché.
