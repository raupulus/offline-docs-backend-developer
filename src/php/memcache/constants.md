## Constantes predefinidas

| Nombre | Descripción |
|----|----|
| `MEMCACHE_COMPRESSED` (`int`) | Utilizada para activar a la volada la compresión de los datos con las funciones `Memcache::set`, `Memcache::add` y `Memcache::replace`. |
| `MEMCACHE_HAVE_SESSION` (`int`) | 1 si el gestor de sesión Memcache está disponible, 0 en caso contrario. |
| `MEMCACHE_USER1` (`int`) | Utilizado para activar los flags de aplicación definidos por los usuarios, con los métodos `Memcache::set`, `Memcache::add` y `Memcache::replace`. |
| `MEMCACHE_USER2` (`int`) | Utilizado para activar los flags de aplicación definidos por los usuarios, con los métodos `Memcache::set`, `Memcache::add` y `Memcache::replace`. |
| `MEMCACHE_USER3` (`int`) | Utilizado para activar los flags de aplicación definidos por los usuarios, con los métodos `Memcache::set`, `Memcache::add` y `Memcache::replace`. |
| `MEMCACHE_USER4` (`int`) | Utilizado para activar los flags de aplicación definidos por los usuarios, con los métodos `Memcache::set`, `Memcache::add` y `Memcache::replace`. |
