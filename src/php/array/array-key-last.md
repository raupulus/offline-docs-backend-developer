array_key_last

Recupera la última clave de un array

## Descripción

```php
array_key_last(array $array): int
```php

Recupera la última clave del array `array` dado sin afectar el puntero interno del array.

## Parámetros

`array`  
Un array.

## Valores devueltos

Devuelve la última clave de `array` si el array no está vacío; `null` en caso contrario.
