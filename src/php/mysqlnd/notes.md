## Notas

En esta sección se ofrece una colección de diversas notas sobre el uso del Controlador Nativo de MySQL.

- Utilizar `mysqlnd` significa que se están utilizando flujos PHP para la conectividad subyacente. Para `mysqlnd`, se debe consultar la documentación de flujos de PHP ([???](#book.stream)) para detalles como la configuración del tiempo de espera, y no la documentación para la Biblioteca Cliente de MySQL.
