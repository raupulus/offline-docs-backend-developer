ibase_errcode

Devuelve el código de error iBase

## Descripción

```php
ibase_errcode(): int
```php

Devuelve el código de error resultante de la llamada más reciente a una función InterBase.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve el código de error, en forma de un `int`, o `false` si no ha ocurrido ningún error.
