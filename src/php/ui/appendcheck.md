UI\Menu::appendCheck

Añade un elemento de menú comprobable

## Descripción

```php
public UI\Menu::appendCheck(string $name, [string $type]): UI\MenuItem
```php

Se añadirá un elemento del menú comprobable

## Parámetros

`name`  
El nombre (texto) del nuevo elemento

`type`  
El tipo para el nuevo elemento

## Valores devueltos

Un elemento de menú construido y comprobable del tipo dado
