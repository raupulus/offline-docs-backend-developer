UI\Menu::appendQuit

Añade elemento de menú salir

## Descripción

```php
public UI\Menu::appendQuit([string $type]): UI\MenuItem
```php

Se añadirá un elemento del menú de salida

## Parámetros

`type`  
El tipo para el nuevo elemento

## Valores devueltos

Un elemento del menú de salida construido del tipo dado
