UI\Draw\Brush::setColor

Define el color

## Descripción

```php
public UI\Draw\Brush::setColor(UI\Draw\Color $color): void
```php

```php
public UI\Draw\Brush::setColor(int $color): void
```

Establece el color de este pincel al color suministrado

## Parámetros

`color`  
Puede ser un objeto UI\Draw\Color o un entero RRGGBBAA
