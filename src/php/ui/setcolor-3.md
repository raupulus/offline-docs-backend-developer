UI\Draw\Text\Layout::setColor

Establece el color

## Descripción

```php
public UI\Draw\Text\Layout::setColor(UI\Draw\Color $color, [int $start], [int $end])
```php

```php
public UI\Draw\Text\Layout::setColor(int $color, [int $start], [int $end])
```

Establecerá el color para todo o un rango del texto en el diseño

## Parámetros

`color`  
El color a usar

`start`  
El carácter inicial

`end`  
El carácter final, por defecto el final del string
