UI\Menu::append

Añade elemento de menú

## Descripción

```php
public UI\Menu::append(string $name, [string $type]): UI\MenuItem
```php

Añadirá un nuevo elemento del menú

## Parámetros

`name`  
El nombre (texto) del nuevo elemento

`type`  
El tipo para el nuevo elemento

## Valores devueltos

Un objeto construido del tipo dado
