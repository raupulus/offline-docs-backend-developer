UI\Controls\Tab::setMargin

Define el margen

## Descripción

```php
public UI\Controls\Tab::setMargin(int $page, bool $margin)
```php

Define si se activa o no el margen en la página seleccionada.

## Parámetros

`page`  
La página a seleccionar

`margin`  
Cambio de margen
