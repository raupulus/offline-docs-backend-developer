UI\Area::onKey

Retrollamada de tecla

## Descripción

```php
protected UI\Area::onKey(string $key, int $ext, int $flags)
```php

Debe ser ejecutada en los eventos de tecla

## Parámetros

`key`  
La tecla presionada

`ext`  
La tecla extendida presionada

`flags`  
Modificadores de eventos
