## Instalación/Configuración

## Requisitos

La instalación requiere la biblioteca libui y PHP 7 o una versión más reciente.

Esta extensión requiere la instalación de [la biblioteca libui](https://github.com/andlabs/libui) versión 0.1.0 o una versión más reciente. Consulte la documentación de libui para obtener una lista de los requisitos previos.

## Instalación

Esta extensión [PECL](https://pecl.php.net/) no está integrada en PHP.

Información sobre la instalación de estas extensiones PECL puede ser encontrada en el capítulo del manual titulado [Instalación de extensiones PECL](#install.pecl). Otra información como notas sobre nuevas versiones, descargas, fuentes de ficheros, información sobre los mantenedores así como un CHANGELOG, pueden ser encontradas aquí: <https://pecl.php.net/package/ui>.

Los binarios Windows (los ficheros DLL) para esta extensión PECL están disponibles en el sitio web PECL.
