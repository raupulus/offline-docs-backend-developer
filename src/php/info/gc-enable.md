gc_enable

Activa el colector de referencia circular

## Descripción

```php
gc_enable(): void
```php

Activa el colector de referencia circular, estableciendo [zend.enable_gc](#ini.zend.enable-gc) a `1`.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

No se retorna ningún valor.
