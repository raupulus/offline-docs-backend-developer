getmyuid

Retorna el UID del propietario del script actual

## Descripción

```php
getmyuid(): int
```php

Retorna el UID del propietario del script actual.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Retorna el identificador del propietario del script actual (UID) o `false` en caso de error.

`getmygid`, `getmypid`, `get_current_user`, `getmyinode`, `getlastmod`
