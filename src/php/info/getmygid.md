getmygid

Retorna el GID del propietario del script

## Descripción

```php
getmygid(): int
```php

Retorna el GID del propietario del script.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Retorna el GID del propietario del script actual, o `false` en caso de error.

`getmyuid`, `getmypid`, `get_current_user`, `getmyinode`, `getlastmod`
