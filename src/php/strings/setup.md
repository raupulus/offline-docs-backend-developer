## Instalación/Configuración

## Instalación

No hay instalación necesaria para usar estas funciones, son parte del núcleo de PHP.

A partir de PHP 8.1.0, `crypt` puede ser compilado contra la biblioteca crypt del sistema al especificar la opción de configuración `--with-external-libcrypt`.
