strrev

Invierte un string

## Descripción

```php
strrev(string $string): string
```php

devuelve el `string`, invertido.

## Parámetros

`string`  
El `string` que será invertido.

## Valores devueltos

Devuelve el `string` invertido.

## Ejemplos

Invertir un string con `strrev`

```
<?php
echo strrev("Hola mundo!"); // Imprime "!odnum aloH"
?>

    
```php
