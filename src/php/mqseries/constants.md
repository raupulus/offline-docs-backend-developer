## Constantes predefinidas

Para cada constante WebSphere MQ, existe un equivalente en mqseries.

Para las definiciones y el uso, consulte el "WebSphere MQ Application Programming Guide" y "WebSphere MQ Application Programming Reference red books".

El nombre de las constantes mqseries se forma prefijando el nombre de la constante WebSphere MQ con MQSERIES\_, por ejemplo, las constantes de CompletionCode son:

| Constante PHP           | Constante MQ |
|-------------------------|--------------|
| `MQSERIES_MQCC_OK`      | MQCC_OK      |
| `MQSERIES_MQCC_WARNING` | MQCC_WARNING |
| `MQSERIES_MQCC_FAILED`  | MQCC_FAILED  |
| `MQSERIES_MQCC_UNKNOWN` | MQCC_UNKNOWN |
