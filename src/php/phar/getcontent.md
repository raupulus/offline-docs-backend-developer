PharFileInfo::getContent

Obtiene el contenido completo del fichero de la entrada

## Descripción

```php
public PharFileInfo::getContent(): string
```php

Esta función se comporta como `file_get_contents` pero para Phar.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve el contenido del fichero.
