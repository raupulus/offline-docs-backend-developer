mysqli_connect

Alias de

mysqli::\_\_construct

## Descripción

Esta función es un alias de: mysqli::\_\_construct

> [!NOTE]
> Si el modo de excepción mysqli no está activado y una conexión falla, entonces `mysqli_connect` retorna `false` en lugar de un objeto. La función `mysqli_connect_error` puede ser utilizada para recuperar el error de conexión.
