Gmagick::rollimage

Compensa una imagen

## Descripción

```php
public Gmagick::rollimage(int $x, int $y): Gmagick
```php

Compensa una imagen tal como está definido por x e y.

## Parámetros

`x`  
El índice x.

`y`  
El índice y.

## Valores devueltos

El objeto Gmagick si se tuvo éxito

## Errores/Excepciones

Emite una excepción `GmagickException` en caso de error.
