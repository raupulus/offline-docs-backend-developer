Gmagick::getfilename

El nombre de archivo asociado a una secuencia de imágenes

## Descripción

```php
public Gmagick::getfilename(): string
```php

Devuelve el nombre de archivo asociado a una secuencia de imágenes.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve una cadena si se tuvo éxito.

## Errores/Excepciones

Emite una excepción `GmagickException` en caso de error.
