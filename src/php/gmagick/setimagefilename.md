Gmagick::setimagefilename

Define el nombre del fichero para una imagen particular de una secuencia

## Descripción

```php
public Gmagick::setimagefilename(string $filename): Gmagick
```php

Define el nombre del fichero para una imagen particular de una secuencia.

## Parámetros

`filename`  
El nombre del fichero de la imagen.

## Valores devueltos

El objeto `Gmagick`.

## Errores/Excepciones

Emite una excepción `GmagickException` en caso de error.
