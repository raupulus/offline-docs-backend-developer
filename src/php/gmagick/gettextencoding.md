GmagickDraw::gettextencoding

Devuelve el conjunto de codificación usado para anotaciones de texto

## Descripción

```php
public GmagickDraw::gettextencoding(): mixed
```php

Devuelve una cadena que especifica el conjunto de codificación usado para anotaciones de texto.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve una cadena que especifica el conjunto de codificación o `false` si no está establecida ningúna codificación.
