GmagickDraw::setstrokecolor

Establece el color usado para contornear los perfiles del objeto

## Descripción

```php
public GmagickDraw::setstrokecolor(mixed $color): GmagickDraw
```php

Establece el color usado para contornear los perfiles del objeto.

## Parámetros

`color`  
Un objeto `GmagickPixel` o un `string` que representa el color del contorno.

## Valores devueltos

El objeto `GmagickDraw` si se tuvo éxito
