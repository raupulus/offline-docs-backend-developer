Gmagick::getversion

Devuelve la versión de la API GraphicsMagick

## Descripción

```php
public Gmagick::getversion(): array
```php

Devuelve la versión de la API GraphicsMagick como una cadena y como un número.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve la versión de la API GraphicsMagick como una cadena y como un número.

## Errores/Excepciones

Emite una excepción `GmagickException` en caso de error.
