Gmagick::setimageformat

Define el formato de una imagen

## Descripción

```php
public Gmagick::setimageformat(string $imageFormat): Gmagick
```php

Define el formato de una imagen particular de una secuencia.

## Parámetros

`imageFormat`  
El formato de la imagen.

## Valores devueltos

El objeto `Gmagick`.

## Errores/Excepciones

Emite una excepción `GmagickException` en caso de error.
