GmagickDraw::getfontstyle

Devuelve el estilo de fuente

## Descripción

```php
public GmagickDraw::getfontstyle(): int
```php

Devuelve el estilo de fuente usado cuando se anota texto.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve la constante de estilo de fuente (STYLE\_) asociada con el objeto `GmagickDraw` o `0` si no está establecido ningún estilo.
