Gmagick::setfilename

Define el nombre de archivo antes de leer o escribir una imagen

## Descripción

```php
public Gmagick::setfilename(string $filename): Gmagick
```php

Define el nombre de archivo antes de leer o escribir una imagen.

## Parámetros

`filename`  
El nombre de archivo de la imagen.

## Valores devueltos

El objeto `Gmagick`.

## Errores/Excepciones

Emite una excepción `GmagickException` en caso de error.
