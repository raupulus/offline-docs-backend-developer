## Controladores PDO

Los siguientes controladores están actualmente implementados en la interfaz PDO:

| Nombre del controlador | Bases de datos soportadas |
|----|----|
| [PDO_CUBRID](#ref.pdo-cubrid) | Cubrid |
| [PDO_DBLIB](#ref.pdo-dblib) | FreeTDS / Microsoft SQL Server / Sybase |
| [PDO_FIREBIRD](#ref.pdo-firebird) | Firebird |
| [PDO_IBM](#ref.pdo-ibm) | IBM DB2 |
| [PDO_INFORMIX](#ref.pdo-informix) | IBM Informix Dynamic Server |
| [PDO_MYSQL](#ref.pdo-mysql) | MySQL 3.x/4.x/5.x/8.x |
| [PDO_OCI](#ref.pdo-oci) | Oracle Call Interface |
| [PDO_ODBC](#ref.pdo-odbc) | ODBC v3 (IBM DB2, unixODBC y win32 ODBC) |
| [PDO_PGSQL](#ref.pdo-pgsql) | PostgreSQL |
| [PDO_SQLITE](#ref.pdo-sqlite) | SQLite 3 y SQLite 2 |
| [PDO_SQLSRV](#ref.pdo-sqlsrv) | Microsoft SQL Server / SQL Azure |
