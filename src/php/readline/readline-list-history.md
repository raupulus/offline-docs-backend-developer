readline_list_history

Lista el historial

## Descripción

```php
readline_list_history(): array
```php

Lista el historial.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve un array con la lista de todas las líneas de comandos del historial. Los elementos están indexados numéricamente, a partir de `0`.
