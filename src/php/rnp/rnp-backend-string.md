rnp_backend_string

Devuelve el nombre de la biblioteca back-end de criptografía

## Descripción

```php
rnp_backend_string(): string
```php

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

El nombre de la biblioteca back-end de criptografía. Las bibliotecas de criptografía soportadas son "Botan" y "OpenSSL".
