oauth_urlencode

Códifica una URI a RFC 3986

## Descripción

```php
oauth_urlencode(string $uri): string
```php

Códifica una URI a [RFC 3986](https://datatracker.ietf.org/doc/html/rfc3986).

## Parámetros

`uri`  
URI a codificar.

## Valores devueltos

Devuelve una cadena codificada según [RFC 3986](https://datatracker.ietf.org/doc/html/rfc3986).
