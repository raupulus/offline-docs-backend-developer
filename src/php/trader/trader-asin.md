trader_asin

Arcoseno trigonométrico de vectores

## Descripción

```php
trader_asin(array $real): array
```php

Calcula el seno para cada valor de `real` y devuelve el array resultante.

## Parámetros

`real`  
Array de valores reales.

## Valores devueltos

Devuelve un array con los datos calculados o false en caso de fallo.
