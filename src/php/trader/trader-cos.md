trader_cos

Coseno trigonométrico de vectores

## Descripción

```php
trader_cos(array $real): array
```php

Calcula el coseno para cada valor de `real` y devuelve el array resultante.

## Parámetros

`real`  
Array de valores reales.

## Valores devueltos

Devuelve un array con los datos calculados o false en caso de fallo.
