trader_errno

Obtener el código de error

## Descripción

```php
trader_errno(): int
```php

Obtener el código de error de la última operación.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

Devuelve el código de error identificado por una de las constantes [TRADER_ERR\_\*](#trader.constants).
