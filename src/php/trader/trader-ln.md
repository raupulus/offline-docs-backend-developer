trader_ln

Logaritmo natural de vectores

## Descripción

```php
trader_ln(array $real): array
```php

Calcula el logaritmo natural para cada valor de `real` y devuelve el array resultante.

## Parámetros

`real`  
Array de valores reales.

## Valores devueltos

Devuelve un array con los datos calculados o false en caso de error.
