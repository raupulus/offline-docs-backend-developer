trader_acos

Arcocoseno trigonométrico de vectores

## Descripción

```php
trader_acos(array $real): array
```php

Calcula el arcocoseno para cada valor de `real` y devuelve el array resultante.

## Parámetros

`real`  
Array de valores reales.

## Valores devueltos

Devuelve un array con los datos calculados o false en caso de fallo.
