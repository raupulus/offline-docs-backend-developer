trader_ceil

Redondeo hacia arriba de vectores

## Descripción

```php
trader_ceil(array $real): array
```php

Calcula el siguiente entero mayor para cada valor de `real` y devuelve el array resultante.

## Parámetros

`real`  
Array de valores reales.

## Valores devueltos

Devuelve un array con los datos calculados o false en caso de fallo.
