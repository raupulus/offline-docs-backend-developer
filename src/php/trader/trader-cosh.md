trader_cosh

Coseno hiperbólico de un vector

## Descripción

```php
trader_cosh(array $real): array
```php

Calcula el coseno hiperbólico para cada valor de `real` y devuelve el array resultante.

## Parámetros

`real`  
Array de valores reales.

## Valores devueltos

Devuelve un array con los datos calculados o false en caso de fallo.
