trader_add

Suma aritmética de vectores

## Descripción

```php
trader_add(array $real0, array $real1): array
```php

Calcula la suma de vectores de `real0` a `real1` y devuelve el vector resultante.

## Parámetros

`real0`  
Array de valores reales.

`real1`  
Array de valores reales.

## Valores devueltos

Devuelve un array con los datos calculados o false en caso de fallo.
