## Instalación

Utilice `--with-pdo-pgsql[=DIR]` para instalar la extensión PDO PostgreSQL, donde el opcional `[=DIR]` es el directorio base de la instalación de PostgreSQL o la ruta a *pg_config*.

    $ ./configure --with-pdo-pgsql
