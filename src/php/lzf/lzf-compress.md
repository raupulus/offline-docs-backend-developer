lzf_compress

Compresión LZF

## Descripción

```php
lzf_compress(string $data): string
```php

`lzf_compress` comprime el string `data` dado utilizando codificación LZF.

## Parámetros

`data`  
El string a comprimir.

## Valores devueltos

Devuelve los datos comprimidos o `false` si ocurrió un error.
