fann_get_num_input

Obtener el número de neuronas de entrada

## Descripción

```php
fann_get_num_input(resource $ann): int
```php

Obtener el número de neuronas de entrada.

## Parámetros

`ann`  
Un `resource` de red neuronal.

## Valores devueltos

El número de neuronas de entrada, o `false` en caso de error.
