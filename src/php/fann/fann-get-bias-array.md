fann_get_bias_array

Obtener el número de tendencias de cada capa de una red

## Descripción

```php
fann_get_bias_array(resource $ann): array
```php

Obtener el número de tendencias de cada capa de una red.

## Parámetros

`ann`  
Un `resource` de red neuronal.

## Valores devueltos

Un array con de números de tendencias en cada capa.
