fann_print_error

Imprime el string de error

## Descripción

```php
fann_print_error(resource $errdat): void
```php

Imprime el string de error.

## Parámetros

`errdat`  
O bien un `resource` de red neuronal, o un `resource` de datos de entrenamiento de red neuronal.

## Valores devueltos

No devuelve ningún valor.
