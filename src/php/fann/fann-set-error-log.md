fann_set_error_log

Establece dónde registrar los errores

## Descripción

```php
fann_set_error_log(resource $errdat, string $log_file): void
```php

Establece dónde registrar los errores.

## Parámetros

`errdat`  
O bien un `resource` de red neuronal, o un `resource` de datos de entrenamiento de red neuronal.

`log_file`  
La ruta al fichero de registro.

## Valores devueltos

No devuelve ningún valor.
