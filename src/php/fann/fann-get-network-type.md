fann_get_network_type

Obtener el tipo de una red neuronal

## Descripción

```php
fann_get_network_type(resource $ann): int
```php

Obtener el tipo de una red neuronal.

## Parámetros

`ann`  
Un `resource` de red neuronal.

## Valores devueltos

Una constante de [tipo de red](#constants.fann-nettype), o `false` en caso de error.
