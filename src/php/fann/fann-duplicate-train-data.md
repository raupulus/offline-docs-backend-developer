fann_duplicate_train_data

Devuelve una copia exacta de uno datos de entrenamiento de fann

## Descripción

```php
fann_duplicate_train_data(resource $data): resource
```php

Devuelve una copia exacta de un `resource` de datos de entrenamiento de fann.

## Parámetros

`data`  
Un `resource` de datos de entrenamiento de red neuronal.

## Valores devueltos

Devuelve un `resource` de datos de entrenamiento en caso de éxito, o `false` en caso de error.
