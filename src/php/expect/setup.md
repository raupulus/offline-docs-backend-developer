## Instalación/Configuración

## Requisitos

Este módulo utiliza las funciones de la biblioteca [expect](http://expect.nist.gov/). Se necesita la versión de libexpect \>= 5.43.0.

## Tipos de recursos

`expect_popen` devuelve el flujo del PTY usado por `expect_expectl`.
