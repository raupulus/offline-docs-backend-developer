Componere\Definition::getClosures

Obtener Cierres

## Descripción

```php
public Componere\Definition::getClosures(): array
```php

Devolverá un array de cierres

## Valores devueltos

Devolverá todos los métodos como un array de objetos de cierre vinculados al alcance correcto

## Excepciones

> [!WARNING]
> Lanzará `RuntimeException` si `Definition` se registró
