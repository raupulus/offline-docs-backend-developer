mysql_xdevapi\Client::close

Cierra el cliente

## Descripción

```php
public mysql_xdevapi\Client::close(): bool
```php

Cierra todas las conexiones del cliente con el servidor.

## Parámetros

Esta función no contiene ningún parámetro.

## Valores devueltos

`true` si las conexiones son cerradas.
