## Instalación/Configuración

## Requisitos

PHP debe ser compilado con la opción `--enable-exif`. Para activar el soporte de etiquetas EXIF multibyte, la extensión [mbstring](#ref.mbstring) debe ser activada durante la compilación con `--enable-mbstring`. PHP no requiere ninguna biblioteca adicional para el funcionamiento del módulo exif.
