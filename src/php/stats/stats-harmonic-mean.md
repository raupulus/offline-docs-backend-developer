stats_harmonic_mean

Devuelve la media armónica de un array de valores

## Descripción

```php
stats_harmonic_mean(array $a): number
```php

Devuelve la media armónica de los valores de `a`.

## Parámetros

`a`  
El array de entrada

## Valores devueltos

Devuelve la media armónica de los valores de `a`, o `false` si `a` está vacío o no es un array.
