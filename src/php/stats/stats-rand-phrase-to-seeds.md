stats_rand_phrase_to_seeds

Genera dos semillas para el generador de números aleatorios RGN

## Descripción

```php
stats_rand_phrase_to_seeds(string $phrase): array
```php

Genera dos semillas para el generador de números aleatorios a partir de una `phrase`.

## Parámetros

`phrase`  
La frase de entrada

## Valores devueltos

Devuelve un array de dos enteros.
