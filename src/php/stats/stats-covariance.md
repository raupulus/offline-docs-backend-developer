stats_covariance

Calcula la covarianza de dos conjuntos de datos

## Descripción

```php
stats_covariance(array $a, array $b): float
```php

Devuelve la covarianza de `a` y `b`.

## Parámetros

`a`  
El primer array

`b`  
El segundo array

## Valores devueltos

Devuelve la covarianza de `a` y `b`, o `false` en caso de fallo.
