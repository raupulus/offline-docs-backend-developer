stats_stat_innerproduct

Devuelve el producto interno de dos vectores

## Descripción

```php
stats_stat_innerproduct(array $arr1, array $arr2): float
```php

Devuelve el producto interno de `arr1` y `arr2`.

## Parámetros

`arr1`  
El primer array

`arr2`  
El segundo array

## Valores devueltos

Devuelve el producto interno de `arr1` y `arr2`, o `false` en caso de error.
