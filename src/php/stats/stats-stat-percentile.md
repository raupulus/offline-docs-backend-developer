stats_stat_percentile

Devuelve el valor del percentil

## Descripción

```php
stats_stat_percentile(array $arr, float $perc): float
```php

Devuelve el valor del `perc`-ésimo percentil del conjunto de datos `arr`.

## Parámetros

`arr`  
El array de entrada

`perc`  
El percentil

## Valores devueltos

Devuelve el percentil del conjunto de datos.
