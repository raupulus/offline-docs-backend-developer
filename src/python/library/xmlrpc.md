# "xmlrpc" --- Módulos XMLRPC para cliente y servidor

XML-RPC es un método de Llamada a Procedimiento Remoto (o RPC en
inglés) que usa XML usando HTTP como vía de transporte. Con esto, un
cliente puede llamar a método con parámetros en un servidor remoto (el
servidor se identifica mediante una URI) y traer de vuelta datos de
forma estructurada.

"xmlrpc" es un paquete que agrupa los módulos, tanto de cliente como
de servidor, que implementan XML-RPC. Los módulos son:

* "xmlrpc.client"

* "xmlrpc.server"
