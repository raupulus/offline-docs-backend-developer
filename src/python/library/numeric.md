# Módulos numéricos y matemáticos

Los módulos descritos en este capítulo proporcionan funciones y tipos
de datos numéricos y relacionados con las matemáticas. El módulo
"numbers" define una jerarquía abstracta de tipos numéricos. Los
módulos "math" y "cmath" contienen varias funciones matemáticas para
números complejos y de punto flotante. El módulo "decimal" admite
representaciones exactas de números decimales, utilizando aritmética
de precisión arbitraria.
