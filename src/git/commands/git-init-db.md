git-init-db(1) ==============

NAME ---- git-init-db - Creates an empty Git repository

SYNOPSIS --------

> ’git init-db’ \[-q \| --quiet\] \[--bare\] \[--template=\<template-directory\>\] \[--separate-git-dir \<git-dir\>\] \[--shared\[=\<permissions\>\]\]

DESCRIPTION -----------

This is a synonym for [git-init](git-init.md). Please refer to the documentation of that command.
