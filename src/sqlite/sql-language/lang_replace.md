The REPLACE command is an alias for the "[INSERT OR REPLACE](lang_conflict.md)" variant of the [INSERT](lang_insert.md) command. This alias is provided for compatibility other SQL database engines. See the [INSERT](lang_insert.md) command documentation for additional information.
