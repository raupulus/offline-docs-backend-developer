> \
> int sqlite3_extended_result_codes(sqlite3\*, int onoff);\

The sqlite3_extended_result_codes() routine enables or disables the [extended result codes](../rescode.md#extrc) feature of SQLite. The extended result codes are disabled by default for historical compatibility.
