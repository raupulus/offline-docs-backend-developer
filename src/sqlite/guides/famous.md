## Well-Known Users of SQLite

SQLite is used by literally millions of applications with literally billions and billions of deployments. SQLite is the [most widely deployed](mostdeployed.md) database engine in the world today.

A few of the better-known users of SQLite are shown below in alphabetical order. This is not a complete list. SQLite is in the [public domain](copyright.md) and so most developers use it in their projects without ever telling us.

------------------------------------------------------------------------

<a href="http://www.adobe.com/" data-border="0"><img src="images/foreignlogos/adobe.gif" width="215" /></a>

[Adobe](http://www.adobe.com/) uses SQLite as the [application file format](whentouse.md#appfileformat) for their [Photoshop Lightroom](http://www.adobe.com/products/photoshoplightroom/) product. SQLite is also a standard part of the [Adobe Integrated Runtime (AIR)](https://airsdk.harman.com). It is reported that [Acrobat Reader](http://www.adobe.com/products/acrobat/readstep2.html) also uses SQLite.

------------------------------------------------------------------------

<a href="http://www.airbus.com/" data-border="0"><img src="images/foreignlogos/airbus2.gif" width="215" /></a>

[Airbus](http://www.airbus.com/) confirms that SQLite is being used in the flight software for the [A350 XWB](https://www.airbus.com/en/products-services/commercial-aircraft/passenger-aircraft/a350-family) family of aircraft.

------------------------------------------------------------------------

<a href="http://www.apple.com/" data-border="0"><img src="images/foreignlogos/apple.gif" width="215" /></a>

[Apple](http://www.apple.com/) uses SQLite in many (most?) of the native applications running on Mac OS-X desktops and servers and on iOS devices such as iPhones and iPods. SQLite is also used in [iTunes](http://www.apple.com/itunes/), even on non-Apple hardware.

------------------------------------------------------------------------

<a href="http://www.bentley.com/" data-border="0"><img src="images/foreignlogos/bentley.gif" width="215" /></a>

[Bentley Systems](http://www.bentley.com/) uses SQLite as the [application file format](aff_short.md) for their [Microstation](https://www.bentley.com/en/products/product-line/modeling-and-visualization-software/microstation) CAD/CAM product.

------------------------------------------------------------------------

<a href="http://oss.bosch-cm.com/index.html" data-border="0"><img src="images/foreignlogos/bosch_logo1.gif" width="215" /></a>

[Bosch](http://www.bosch.com/) uses SQLite in the multimedia systems install on GM, Nissan, and Suzuki automobiles. ([link](http://oss.bosch-cm.com/index.html))

------------------------------------------------------------------------

<a href="http://www.dropbox.com/" data-border="0"><img src="images/foreignlogos/dropbox.gif" width="215" /></a>

The increasingly popular [Dropbox](http://www.dropbox.com/) file archiving and synchronization service is reported to use SQLite as the primary data store on the client side.

------------------------------------------------------------------------

<a href="https://www.expensify.com/" data-border="0"><img src="images/foreignlogos/expensify.png" width="215" /></a>

[Expensify](https://www.expensify.com/) uses SQLite as a server-side database engine for their enterprise-scale expense reporting software.

------------------------------------------------------------------------

<a href="https://www.facebook.com/" data-border="0"><img src="images/foreignlogos/fb.gif" width="215" /></a>

[Facebook](https://www.facebook.com/) uses SQLite as the SQL database engine in their [osquery](https://code.facebook.com/projects/658950180885092) product.

------------------------------------------------------------------------

<a href="http://www.ge.com/" data-border="0"><img src="images/foreignlogos/ge.gif" width="215" /></a>

We believe that [General Electric](http://www.ge.com/) uses SQLite in some product or another because they have written to the SQLite developers at least four separate times requesting the US Export Control Number for SQLite. So presumably GE is using SQLite in something that they are exporting. But nobody (outside of GE) seems to know what that might be.

------------------------------------------------------------------------

<a href="http://www.google.com/" data-border="0"><img src="images/foreignlogos/google.gif" width="215" /></a>

uses SQLite in their [Android](http://code.google.com/android/) cell-phone operating system, and in the [Chrome Web Browser](http://www.google.com/chrome).

------------------------------------------------------------------------

<a href="http://www.intuit.com/" data-border="0"><img src="images/foreignlogos/intuit.gif" width="215" /></a>

[Intuit](http://www.intuit.com/) apparently uses SQLite in [QuickBooks](http://www.quickbooks.com/) and in [TurboTax](http://turbotax.intuit.com/) to judge from some error reports from users seen [here](http://community.intuit.com/posts/database-error-sqlite-error-code1) and [here](https://ttlc.intuit.com/post/show_full/cJf8mIhC4r4jjracfArQzM/when-i-try-to-update-turbotax-i-receive-an-unexpected-error-message).

------------------------------------------------------------------------

<a href="http://www.loc.gov/" data-border="0"><img src="images/foreignlogos/loc.jpg" width="215" /></a>

The United States Library of Congress recognizes SQLite as a [recommended storage format](locrsf.md) for preservation of digital content.

------------------------------------------------------------------------

<a href="http://www.mcafee.com/" data-border="0"><img src="images/foreignlogos/mcaffee.gif" width="215" /></a>

[McAfee](http://www.mcafee.com/) uses SQLite in its antivirus programs. Mentioned [here](http://www.mail-archive.com/sqlite-users@sqlite.org/msg16931.html) and implied [here](https://forums.mcafee.com/t5/WebAdvisor/SQLite-Temporary-Files/m-p/19512).

------------------------------------------------------------------------

<a href="http://www.microsoft.com/" data-border="0"><img src="images/foreignlogos/microsoft.gif" width="215" /></a>

[Microsoft](http://www.microsoft.com/) uses SQLite as a core component of Windows 10, and in other products.

------------------------------------------------------------------------

<a href="http://www.mozilla.com/" data-border="0"><img src="images/foreignlogos/firefox.gif" width="215" /></a>

SQLite is the primary meta-data storage format for the [Firefox Web Browser](http://www.mozilla.com/) and the [Thunderbird Email Reader](http://www.mozilla.com/thunderbird/) from Mozilla.

------------------------------------------------------------------------

<a href="http://www.nds-association.org/" data-border="0"><img src="images/foreignlogos/nds.png" width="215" /></a>

[The Navigation Data Standard](http://www.nds-association.org/) uses SQLite as its [application file format](aff_short.md).

------------------------------------------------------------------------

<a href="http://www.php.net/" data-border="0"><img src="images/foreignlogos/php.gif" width="215" /></a>

The popular [PHP](http://www.php.net/) programming language comes with both SQLite2 and SQLite3 built in.

------------------------------------------------------------------------

<a href="http://www.python.org/" data-border="0"><img src="images/foreignlogos/python.gif" width="215" /></a>

All [Python](http://docs.python.org/lib/module-sqlite3.html) distributions since Python 2.5 include SQLite.

------------------------------------------------------------------------

<a href="https://en.wikipedia.org/wiki/RPM_Package_Manager" data-border="0"><img src="images/foreignlogos/rpm_logo.png" width="215" /></a>

The [RedHat Package Manager (RPM)](https://en.wikipedia.org/wiki/RPM_Package_Manager) uses SQLite to track its state.

------------------------------------------------------------------------

<a href="http://www.skype.com/" data-border="0"><img src="images/foreignlogos/skype.gif" width="215" /></a>

There are [multiple](http://www.mail-archive.com/sqlite-users%40sqlite.org/msg27326.html) [sightings](http://www.mail-archive.com/sqlite-users%40sqlite.org/msg27332.html) of SQLite in the Skype client for Mac OS X and Windows.

------------------------------------------------------------------------

<a href="http://www.tcl-lang.org/" data-border="0"><img src="images/foreignlogos/tcl.gif" width="215" /></a>

The Tcl/Tk programming language now comes with SQLite built-in. SQLite works particularly well with Tcl since SQLite was originally a Tcl extension that subsequently "escaped" into the wild.

------------------------------------------------------------------------

<a href="http://www.xojo.com/" data-border="0"><img src="images/foreignlogos/xojo.png" width="215" /></a>

SQLite comes bundled with the [Xojo](http://www.xojo.com/) programming environment (formerly [REALbasic](http://www.realbasic.com/))
