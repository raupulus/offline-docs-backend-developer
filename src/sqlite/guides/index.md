SQLite is a C-language library that implements a [small](footprint.md), [fast](fasterthanfs.md), [self-contained](selfcontained.md), [high-reliability](hirely.md), [full-featured](fullsql.md), SQL database engine. SQLite is the [most used](mostdeployed.md) database engine in the world. SQLite is built into all mobile phones and most computers and comes bundled inside countless other applications that people use every day. [More Information...](about.md)

SQLite [source code](https://sqlite.org/src) is in the [public-domain](copyright.md) and is free to everyone to use for any purpose.
