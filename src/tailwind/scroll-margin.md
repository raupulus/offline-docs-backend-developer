### Using negative values

To use a negative scroll margin value, prefix the class name with a dash to convert it to a negative value:

```html
<!-- [!code classes:-scroll-ml-6] -->
<div class="snap-start -scroll-ml-6 ...">
  <!-- ... -->
</div>
```
